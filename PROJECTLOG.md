### Done
- **Data layer**: `dataStore.js` downloads + caches the 7 iptv-org datasets to
  `userData/cache`, nightly/manual refresh, offline-tolerant. `catalog.js` joins
  them into ~13k watchable channels with denormalized country/category/language/
  logo/streams and a `computeFacets()` used for the sidebar.
- **Free streaming services**: `providers.js` detects Pluto TV, Samsung TV Plus,
  Plex, Tubi, Stirr, Xumo, Rakuten, Roku, LG Channels from stream URLs (~3.8k
  channels) → a **Service** sidebar filter. (Explicitly NOT paywalled/DRM OTT.)
- **UI** (`src/renderer/`): sidebar filters (Service/Country/Category/Language +
  Favorites/Recent), searchable logo grid with infinite-scroll windowing, docked
  HLS player (hls.js) with fullscreen + PiP, now/next EPG strip, full program-
  guide view, Settings (toggles, custom playlists, EPG URLs).
- **EPG**: `epg.js` streams + parses XMLTV (gzip aware), now/next + range lookups,
  matched by channel id. User-configured sources (iptv-org hosts none).
- **Health-checker**: `health.js` probes streams main-side, caches with TTL,
  flags/hides dead channels.
- **Persistence**: `persistence.js` (electron-store) for favorites / recent /
  settings.
- **Packaging**: electron-builder config for NSIS + portable Windows targets;
  `build/icon.{png,ico}` generated by `scripts/make-icon.js`.
- **Doc spine**: README / AGENTS / CLAUDE / PROJECTLOG + MIT LICENSE.

## REFERENCE

### What it is
Electron (Windows) app aggregating free/public live TV from iptv-org, with EPG,
favorites, custom playlists, and dead-stream hiding.

### Stack
Electron + hls.js + electron-store + sax; electron-builder (NSIS + portable).
Vanilla JS/CSS renderer. No backend.

### Data model
iptv-org datasets joined on `channel.id`; languages from `feeds`; services
detected from stream URLs. Catalog cached to `userData/cache/catalog.json`
(versioned). User state in electron-store `worldtv-user`.

### Loop
main downloads/caches datasets → builds catalog → merges custom playlists →
sends lite channels + facets to renderer → renderer filters/renders → play via
hls.js → health + EPG fetched on demand.

### Env
None. `WORLDTV_DEVTOOLS=1` opens devtools in dev.

### Commands
`npm install`, `npm run dev`, `npm run dist`, `npm run dist:dir`.
